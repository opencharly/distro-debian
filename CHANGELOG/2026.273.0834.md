# 2026.273.0834 — fix(box)!: one source per layer — align debian-coder to stamp-free tags (#717, #739)

## Summary

One-source-per-layer alignment for **`debian-coder`** behind `opencharly/charly#717` / `#739`.

The box referenced the same candies from two configs, so the resolver arbitrated between
them and emitted a within-box multi-tag warning. This change makes each candy resolve from
**ONE** source: it bumps the box's composing meta-layers to their newest tags — every one
**stamp-free** (the retired entity `version:` already removed upstream) — and drops **every**
direct layer ref those meta-layers now provide at **≥** the box's former pin. **No downgrade**:
each provider's transitive pin is `≥` the removed direct ref.

| Meta-layer (bumped) | from → to | now composes |
|---|---|---|

| `layer-google-cloud-npm` | `v2026.240.0201 → v2026.272.0141` | `layer-gemini v2026.243.0409`, `layer-google-cloud v2026.241.0656` |
| `layer-language-runtimes` | `v2026.240.0201 → v2026.272.0320` | `layer-nodejs v2026.239.1624`, `layer-rust v2026.239.1627` |

**Dropped** (now provided at `≥` by the bumped source): `layer-charly v2026.241.1407`,
`layer-direnv v2026.239.1629`, `layer-gemini v2026.239.1621`,
`layer-google-cloud v2026.239.1628`, `layer-nodejs v2026.239.1624`, `layer-rust v2026.239.1627`
(the last two now come from the bumped `layer-language-runtimes`, which composes them at
exactly these pins).

**Rule:** *a box keeps exactly ONE ref per candy — drop whichever of `{pod, layer}` the other's
`candy:` closure already provides.* For this box the **pod is the meta-layer**, so it keeps
`pod-charly-mcp` and drops the redundant direct layers. It is not "always keep the pod": where
the layer is the meta-layer the pod is dropped instead.
